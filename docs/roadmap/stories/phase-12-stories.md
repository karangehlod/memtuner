# Phase 12 Stories

## Workstream: Suite Definition

### AMB-P12-S01: Define benchmark suite inclusion policy
Goal: state which datasets qualify for the standard benchmark suite.
Dependencies: AMB-P02-S04
Acceptance Criteria:
- Inclusion rules documented
- Exclusion rules documented
- Policy ties to benchmark goals
Completion Evidence:
- Inclusion policy note exists
Status: Not Started

### AMB-P12-S02: Select standard benchmark datasets
Goal: define the initial suite used in standard releases and papers.
Dependencies: AMB-P12-S01
Acceptance Criteria:
- Standard dataset list defined
- Selection rationale documented
- Adapter support confirmed
Completion Evidence:
- Benchmark suite selection note exists
Status: Not Started
