# Phase 13 Stories

## Workstream: Experiment Planning

### AMB-P13-S01: Define final paper experiment matrix
Goal: map every major paper claim to a concrete experiment set.
Dependencies: AMB-P12-S04, AMB-P09-S03, AMB-P10-S03
Acceptance Criteria:
- Primary claim-to-experiment mapping exists
- Ablations and sensitivity studies are listed
- Deferred experiments are identified
Completion Evidence:
- Paper experiment matrix exists
Status: Not Started

### AMB-P13-S02: Define experiment manifests and archival rules
Goal: ensure paper experiments are reproducible and auditable.
Dependencies: AMB-P13-S01
Acceptance Criteria:
- Manifest structure defined
- Archival requirements documented
- Artifact completeness rules documented
Completion Evidence:
- Manifest and archival note exists
Status: Not Started

## Workstream: Execution and Paper Assets

### AMB-P13-S03: Execute primary paper experiments
Goal: generate the empirical core of the paper.
Dependencies: AMB-P13-S02
Acceptance Criteria:
- Primary comparisons completed
- Required metadata captured
- Artifacts archived
Completion Evidence:
- Primary paper experiment artifacts exist
Status: Not Started

### AMB-P13-S04: Execute ablations and generate paper tables
Goal: support nuanced benchmark claims and limitations.
Dependencies: AMB-P13-S03
Acceptance Criteria:
- Planned ablations completed
- Paper tables generated from artifacts
- Missing experiments documented explicitly
Completion Evidence:
- Ablation artifacts and tables exist
Status: Not Started
